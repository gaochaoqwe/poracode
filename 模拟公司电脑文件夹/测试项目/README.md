# 模拟公司电脑文件夹 · 测试项目

## 目录结构（三态）

- `未开展/<项目名>/`：测试主管准备 1组织资产 / 2参考项目资料 / 3本项目资料，齐备后移入「进行中」
- `进行中/<项目名>/`：按 P0~P14 建节点子目录（P0-测试申请文件内含 组织资产/参考资料/本项目资料），文件系统驱动按节点状态流转唤醒员工线程
- `已完成/<软件类型>[/<子类>]/<项目名>/`：先按软件类型分、再按产品分（一~八类下分 一光雷/二吊舱/三转塔/四告警/五地防，九外部测试/十搜潜 直接按项目名），项目内含 1测试申请文件 / 2测试过程文件 / 3测试结果文件

## 示例项目

- 未开展：`2026/未开展/示例项目-B回归测试`（三文件夹结构）
- 进行中：`2026/进行中/示例项目-A配置项测试`（P0~P14 结构，可直接启动实测）
- 已完成：`2026/已完成/一系统控制类/一光雷/示例项目-C配置项测试`（三文件夹归档结构）

注：三个示例为不同项目，仅用于展示三种状态的项目内部结构；实际使用中一个项目同一时刻只存在于一个状态目录。
