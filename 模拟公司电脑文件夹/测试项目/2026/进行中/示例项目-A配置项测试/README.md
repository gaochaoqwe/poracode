# 示例项目-A配置项测试（进行中）

本示例展示「进行中」测试项目的内部结构：按 P0~P14 建节点子目录。

- P0-测试申请文件：内含 组织资产 / 参考资料 / 本项目资料
- P1-准入审查：测试项目主管审查资料齐套性（配置项测试需 需求规格说明+代码），输出 通过/不通过
- P2-测试策划：测试主管输出「示例项目-A配置项测试表单 2.00.00」
- P3~P9：文档审查 / 静态分析 / 代码审查 / 动态测试（用例设计→执行→修正→问题单生成）
- P10 表单质量检查 → P11 报告生成 → P12 报告编写 → P13 报告质量检查 → P14 最终报告

文件系统驱动（FlowDriver）扫描「进行中」目录并按节点状态唤醒员工线程：
节点文件夹名带状态前缀（[P0-测试申请文件-进行中] / [P0-测试申请文件-已完成]）。
