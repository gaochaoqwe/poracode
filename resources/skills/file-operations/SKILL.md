# 文件操作原则（所有员工必遵）

本文是 AgentEmployee 数字员工团队的**总文件操作原则**，适用于全体岗位员工在本地工作区、共享区、知识库中创建、读取、修改、移动、删除、命名、归档文件的一切操作。任何岗位、任何任务都必须遵守，除非任务指令明确且与本文冲突（此时先向总主管说明，不擅自违反）。

## 1. 工作区边界（最重要）

- **只操作你的授权目录**。你的岗位绑定了一组授权根目录（`workspacePaths`）。所有读写、新建、修改、移动、删除都必须落在这些授权根**之内**，绝不触碰授权根之外的文件。
- **判断路径是否越界**：对任一目标路径，先求其相对授权根的相对路径；若相对路径以 `..` 开头或为绝对路径，说明越界——停止并报告。
- **共享区**（`_Shared`）：所有岗位可写可读，用于团队协作产物（总 Excel 测试表单、流水线导入文件、项目交付物）。
- **知识库**（`_Knowledge`）：默认**只读**，是企业知识（规范/标准/模板/参考资料）。除非明确授权，绝不修改知识库内容。
- **投递箱**（`_Inbox`）：只读你的任务来源文件，不修改投递箱中的原文件。

## 2. 创建文件

- **命名规范**：`<主题或对象>_<动作或类型>_<YYYYMMDD>.<ext>`。示例：`测试策划_项目A_20261010.docx`、`问题报告单_项目A_20261010.xlsx`。
- 机关材料按模板命名：`<部门>-<材料类型>-<YYYYMMDD>`（如 `质量部-测试总结-20261010.docx`）。
- **内容写全**：文件名反映内容；正文含作者岗位、日期、版本。文档类文件首行注明"生成岗位 / 日期 / 版本"。
- **编码**：文本文件一律 UTF-8；Excel/Word/PPT 按 officecli 规范生成。

## 3. 修改文件

- **优先可逆操作**：能新建/复制就不要原地破坏。修改前若文件有既有内容，先保留一份（或确认有备份/版本记录）。
- **不覆盖未知内容**：若非你创建的文件，修改前先读取，确认不会丢失他人内容；无法确认时先复制为 `_副本` 再改。
- **写操作先确认**：涉及"修改、删除、覆盖、移动、重命名"等不可逆或影响面大的操作，若岗位 `requireApproval: true` 或操作落点在授权根边缘/共享区他人文件，先向总主管或用户确认。

## 4. 删除与移动

- **禁止擅自删除**：不删除任何用户原文件、他人文件、知识库文件。确需删除的临时/自建文件，先移入同目录 `_trash` 子目录而不是直接 `rm`。
- **移动谨慎**：跨目录移动会破坏路径依赖，先确认目标落点在授权根内且不破坏共享引用。

## 5. 归档与增量

- **增量落点固定**：同一主题的新增数据落同一目录的**新文件**（用日期区分），不要不断覆盖同一文件。示例：每周的测试报告是 `报告_项目A_20261010.docx`、`报告_项目A_20261017.docx`，而非反复覆盖一个文件。
- **表单走共享区**：总 Excel 测试表单等多人协作的表单统一放 `_Shared\总Excel测试表单`，按"主题_日期"增量保存，不覆盖历史版本。
- **归档到部门**：机关材料按部门归档到 `20-文档编写\<部门>`，按"部门-类型-日期"增量命名。

## 6. 来源与可追溯

- **记录来源**：基于外部材料（OA/mxt/老板/流水线）产出的文件，在正文或附注写明来源、接收时间、对应任务。
- **不补编**：缺失的数据或字段如实标注"待补充"，绝不编造。来源不明的内容先标注再决定是否使用。

## 7. 安全与保密

- 涉及个人隐私、账号、密钥的文件内容不外泄、不写进日志。
- 公司内网（OA/jprjcp/流水线）的内容只在本机处理，不上传到外部。

## 8. 原则冲突时

- 具体任务 skill 的细则与本文冲突时，**以更严格者为准**；无法判断时先向总主管说明，取得裁决后再操作。
