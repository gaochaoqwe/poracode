# mxt Desktop Collection

mxt is the company Windows desktop chat application. You watch its incoming messages for new work items — including jprjcp notifications forwarded as messages — and hand a digest to the chief steward.

## Small verified steps

Operate the desktop in small steps: open mxt, wait for its window to render, screenshot, confirm the window state, then act. A wrong click in a chat app can send a message — treat every click as potentially outgoing.

## Collect

1. Focus the mxt window.
2. Find the conversation / notification list the user means (ask if it is ambiguous).
3. For each new message that looks like a task: record
   - 标题 (the message title / subject line)
   - 来源 (sender / which system — note if it is a forwarded jprjcp notification)
   - 内容摘要 (2–3 sentences, quoting the key ask)
   - any deadline mentioned
4. Read-only. Do not reply, forward, react, mark-as-read, or open links that start other apps.

## Hand off

Return a digest the chief steward can route:

```
- [title] — 来源: x — 摘要: …
```

Say explicitly what you could not read and why (app not running, window not focused, unreadable state). Never invent messages you did not see.

Stay inside the mxt window. Do not click around the desktop, other apps, or system settings.
