## 1.2 系统概述

### 1.2.1 软件用途

雷达仿真系统软件是雷达仿真系统的核心软件配置项，在实验室/训练环境下生成、模拟和复现雷达从发射、回波产生到信号处理、数据处理、显控显示的全链路工作过程，为雷达整机研制、性能评估、操作人员训练及战术对抗演练提供数字仿真与半实物仿真环境。软件向上与综合显控/指挥控制系统交互，向被测雷达及测试设备输出回波、发射/接收触发时序等激励信号，并接收雷达上报的点迹、航迹、工作参数，形成"仿真激励—被测对象—数据评估"的闭环。

### 1.2.2 软件的一般特性

- **实时性**：实时仿真方式下，回波数据端到端生成延迟不大于 10ms，发射触发时序输出抖动不大于 1μs；
- **多接口**：支持以太网（UDP/TCP）、光纤/万兆网、串口（RS-422/RS-232）、反射内存网等多种物理接口；
- **双平台**：支持 Windows 10/11 与中标麒麟/银河麒麟国产操作系统双平台运行；
- **可配置**：仿真场景、雷达工作参数、目标与环境参数均支持配置化管理，便于后续型号复用；
- **关键性等级**：B 级（一般关键）。

### 1.2.3 仿真工作链路

软件按"仿真准备 → 目标与环境建模 → 发射与激励生成 → 回波产生与输出 → 接收处理（信号处理、数据处理）→ 显控、评估与数据管理 → 接口通信 → 时钟同步与运维"的仿真业务链路组织软件能力，链路中各环节通过统一的接口与数据字典衔接，形成闭环仿真流程，系统组成框图如下：

```
┌──────────────────────────────────────────────────────────────┐
│                    雷达仿真系统软件                            │
├──────────────────────────────────────────────────────────────┤
│  仿真准备与场景管理 │ 目标与环境建模 │ 发射与激励生成           │
├──────────────────────────────────────────────────────────────┤
│  回波产生与输出 │ 接收处理（信号处理/数据处理） │ 显控评估与数据 │
├──────────────────────────────────────────────────────────────┤
│  接口与通信管理（网络/光纤/串口/反射内存网） │ 时钟同步与运维   │

```

# 3 需求

## 3.1 要求的状态和方式

雷达仿真系统软件在单一软件配置项内运行，按运行状态与部署方式两个维度描述要求的状态和方式：运行状态包括就绪、仿真运行（实时仿真方式／非实时仿真方式）、回放与分析、自检与维护、紧急停止；部署方式包括单机方式与分布式协同方式。每个状态与方式对应的需求组见 3.1.1～3.1.6；本文档第 3 章各项需求除特别说明外均适用于就绪状态与仿真运行状态，实时性指标仅在实时仿真方式下考核，分布式协同方式下还应满足 3.2.8 的时钟同步要求。

### 3.1.1 就绪状态

状态（方式）说明：软件已完成场景装载、参数装订与接口链路自检，等待启动仿真。

- 进入条件：场景装载完成、参数装订完成且接口链路自检通过。
- 主要行为：不输出回波数据与触发时序，接口处于监听状态，响应外部控制指令。
- SRS-B-ST-3.1.1-01 就绪状态判定：软件应在满足进入条件后进入就绪状态，并在显控界面上指示当前状态为就绪。

### 3.1.2 仿真运行状态（实时仿真方式／非实时仿真方式）

状态（方式）说明：软件按实时或非实时仿真方式运行仿真任务。

- 进入条件：收到启动仿真指令且场景与参数校验通过。
- 主要行为：实时仿真方式下按实时节拍输出回波数据与发射/接收触发时序；非实时仿真方式下以数据文件形式生成回波数据，不进行实时时序输出。
- SRS-B-ST-3.1.2-01 实时仿真方式：实时仿真方式下，软件应满足 3.2.4 规定的端到端延迟与单周期处理时间要求，并满足 3.2.3 规定的触发时序抖动要求。
- SRS-B-ST-3.1.2-02 非实时仿真方式：非实时仿真方式下，软件应支持离线生成回波数据文件，其数据精度要求与实时方式一致。

### 3.1.3 回放与分析状态

状态（方式）说明：软件对记录数据进行检索、回放与统计分析。

- 进入条件：收到回放或分析指令且记录数据文件校验通过。
- 主要行为：回放记录数据、显示统计结果、与外部上报点迹/航迹数据比对，且不影响实时链路。
- SRS-B-ST-3.1.3-01 回放与分析状态：软件应支持在回放与分析状态下完成记录数据检索、回放、导出与比对分析，该状态的操作不应对实时链路造成影响。

### 3.1.4 自检与维护状态

状态（方式）说明：软件对主要模块与接口链路进行自检，并支持版本升级与回退。

- 进入条件：收到自检/维护指令或软件启动时自动执行。
- 主要行为：输出自检状态报告；升级过程不破坏历史数据，升级失败后可回退到原版本。
- SRS-B-ST-3.1.4-01 自检：软件应能对主要模块与接口链路进行自检并输出状态报告。
- SRS-B-ST-3.1.4-02 升级与回退：软件应支持版本升级与回退，现场升级时间不大于 30 分钟，升级过程不破坏历史数据。

### 3.1.5 紧急停止状态

状态（方式）说明：在操作员发出急停指令或检测到危险状态时，软件停止激励输出。

- 进入条件：收到急停指令，或检测到设备异常、超限或危险状态。
- 主要行为：立即停止回波与触发时序输出、断开激励链路并保存关键数据，仅在人工确认后允许恢复。
- SRS-B-ST-3.1.5-01 急停：软件应支持急停功能，急停后应在 XXXX（待确认）时间内停止激励输出，并保存关键数据。

### 3.1.6 部署方式（单机方式／分布式协同方式）

状态（方式）说明：软件支持单机运行与分布式多机协同运行两种部署方式。

- 进入条件：按部署配置启动软件并完成节点间链路建立。
- 主要行为：单机方式下全部功能在同一台计算机上运行；分布式协同方式下功能分布到多台计算机，通过反射内存网完成共享数据交换与时钟同步。
- SRS-B-ST-3.1.6-01 单机方式：单机方式下，软件应能完成 3.2 规定的全部软件能力需求。
- SRS-B-ST-3.1.6-02 分布式协同方式：分布式协同方式下，软件应通过反射内存网完成共享数据交换与节点间时钟同步，同步误差不大于 XXXX（待确认）。

## 3.2 软件能力需求

### 3.2.1 仿真准备与场景管理

- 能力描述：为一次仿真任务提供场景建立、编辑、保存、加载与删除能力，完成雷达工作参数、环境参数与目标初始参数的配置与装订，是仿真链路的前置环节。
- 输入：操作员配置参数（雷达工作参数、环境参数、目标初始参数）、外部控制指令与装订数据、已有场景文件。
- 输出：场景文件（含版本信息）、装订后的运行参数集、配置确认信息与异常告警。

需求条目：

- SRS-B-C-3.2.1-01 场景管理：支持仿真场景的建立、编辑、保存、加载与删除；场景文件可重复加载，加载后参数应与保存时一致。
- SRS-B-C-3.2.1-02 雷达工作参数配置：支持工作频段、波形、重频、脉宽、扫描方式、扫描周期等雷达工作参数的配置与校验，非法值应被拦截并给出告警。
- SRS-B-C-3.2.1-03 环境参数配置：支持阵地坐标、电磁环境、杂波类型、气象条件等仿真环境参数的配置。
- SRS-B-C-3.2.1-04 场景版本管理与导入导出：支持场景文件的版本管理与导入导出，导入时应校验文件版本与完整性，校验失败应给出告警。
- SRS-B-C-3.2.1-05 控制与参数装订：支持外部系统下发的启动/停止仿真、场景切换、参数装订等控制指令；对越界或非法装订参数应拒绝执行并告警。
- SRS-B-C-3.2.1-06 装载与保存时间（性能）：在场景规模上限 XXXX（待确认）条件下，场景装载与保存时间不大于 XXXX（待确认）。

### 3.2.2 目标与环境建模

- 能力描述：建立目标模型与运动模型，生成与编辑目标航迹，计算目标 RCS 起伏；生成地物、海面、气象等杂波及压制式/欺骗式干扰，为回波产生环节提供目标与环境数据源。
- 输入：目标初始状态参数（位置、速度、加速度、RCS、机动方式）、航迹编辑指令、RCS 起伏模型选择、杂波类型与幅度分布参数、干扰机位置/功率/干扰样式参数。
- 输出：各仿真时刻目标的位置/速度/姿态与 RCS 值、目标航迹数据、杂波数据、干扰信号数据。

需求条目：

- SRS-B-C-3.2.2-01 目标建模：支持点目标、面目标、扩展目标等目标模型的建立与参数配置。
- SRS-B-C-3.2.2-02 运动模型：支持匀速、匀加速、机动转弯、蛇形机动等多种目标运动模型。
- SRS-B-C-3.2.2-03 航迹编辑与批量生成：支持目标航迹的编辑、批量生成以及实时插入/删除。
- SRS-B-C-3.2.2-04 RCS 起伏模型：支持 Swerling 0～Ⅳ 型目标 RCS 起伏模型的选择与参数设置。
- SRS-B-C-3.2.2-05 杂波仿真：支持地物、海面、气象等类型杂波仿真，杂波幅度统计特性可选择瑞利、对数正态、韦布尔、K 分布。
- SRS-B-C-3.2.2-06 压制式干扰：支持噪声调频、噪声调幅、噪声调相等压制式干扰仿真。
- SRS-B-C-3.2.2-07 欺骗式干扰：支持距离拖引、速度拖引、假目标、多假目标等欺骗式干扰仿真。
- SRS-B-C-3.2.2-08 干扰参数配置：支持干扰机位置、功率、干扰样式等参数的配置与校验。
- SRS-B-C-3.2.2-09 建模规模与精度（性能）：同时仿真的运动目标数量不小于 500 批，场景中目标最大总数不小于 2000 个；目标距离仿真精度不大于 1m（或按雷达距离分辨单元折算），速度仿真精度不大于 0.1m/s；杂波单元数量上限 XXXX（待确认），同时仿真的干扰源数量上限 XXXX（待确认），杂波幅度统计特性误差 XXXX（待确认）。

### 3.2.3 雷达发射与激励生成

- 能力描述：生成雷达发射波形，建模发射功率与天线方向图，产生并同步输出发射触发时序，构成对被测雷达的激励源头。
- 输入：波形类型与参数、发射功率与天线方向图参数、外部同步信号。
- 输出：发射波形数据、天线方向图数据、PRF 发射触发时序与同步脉冲。

## 6.2 术语定义

- a) 雷达仿真：利用数学模型与信号处理手段，对雷达工作过程及其产生的回波、点迹、航迹等信号/数据进行模拟复现的过程；
- b) 半实物仿真：将仿真计算机与被测真实设备通过接口互联、进行实时闭环激励与回传的仿真方式；
- c) 端到端生成延迟：从仿真时钟节拍到来至回波数据输出至接口的完整处理时延；
- d) 致命性故障：导致仿真任务中断且无法自动恢复的故障。
