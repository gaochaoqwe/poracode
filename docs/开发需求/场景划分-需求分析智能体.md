# 使用场景划分：需求分析智能体（REQ-AGENT）

> 配套需求文档：《需求分析智能体软件需求规格说明书_0824.md》
> 目的：把需求文档拆成一个个「用户能用 AgentEmployee + 某个 agent 直接完成」的具体场景，作为后续开发 skill / plugin / 定制模块的依据。

## 一、范围说明

- 本文只划分 **agent 可执行** 的场景（生成 / 检查 / 反推 / 追踪 / 编辑）。
- 纯平台基础能力（登录、并发、空间隔离、备份回退、日志、统计上报等）不展开，统一列在文末「平台侧能力」。
- 需求文档中「以 Web 端访问」的形态，落到 AgentEmployee 上等价为 **桌面端聊天线程 + 文件读写 + 权限/计划中断**；VS Code / Web 宿主形态属平台侧。

### 实现形态图例

| 形态 | 含义 | 判定依据 |
| --- | --- | --- |
| **Skill** | 一个 `SKILL.md`，纯流程/规则/模板知识，模型推理 + 读写文件即可完成 | 不需要外部服务或进程 |
| **Plugin** | Agent Plugins 包（`plugin.json` + skill + `mcp.json`），给 skill 挂外部工具 | 需要文档解析、向量检索、图表渲染、代码索引等工具 |
| **定制模块 / 页面** | supervisor / renderer 里新增代码与 UI | 需要结构化持久化、可视化页面、跨文档关系图 |
| **复用现有** | AgentEmployee 已具备，无需新开发 | 编辑器 / diff 审阅、权限与计划中断、附件导入、provider 配置 |

## 二、使用场景

| # | 场景 | 一句话描述 | 输入 → 输出 | 推荐实现形态 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | 生成软件需求文档 | 按支撑材料 + 模板生成结构化软件需求规格 | 初稿需求/系统需求/任务书/接口文件 + 提示词 → 需求条目 + 需求文本 | **Skill** + Plugin（文档解析） | 核心场景。skill 规定「先出条目框架 → 用户确认 → 补全正文」的两段式流程与模板；文档解析靠 MCP |
| 2 | 生成软件设计文档 | 按需求材料 + 设计模板生成软件设计文档（架构/功能/接口） | 需求文档/技术协议 + 技术约束 → 设计条目 + 设计文本 | **Skill** + Plugin（文档解析） | 与场景 1 同构，差别在模板与架构约束（分层/微服务）写进 skill |
| 3 | 需求质量检查 | 逐条 + 跨条检查歧义/重复/冲突/不可验证/术语不一致 | 结构化需求 + 规则 → 问题清单（位置/类型/严重度/建议） | **Skill** | 纯推理 + 规定输出格式；不做最终裁决，输出供用户确认 |
| 4 | 设计质量检查 | 检查设计完整性、模块职责、接口缺失、异常覆盖 | 结构化设计 + 规则 → 问题清单 | **Skill** | 同场景 3 |
| 5 | 需求逻辑自洽性验证 | 提取状态/接口/时序要素，查死锁/不可达/转换缺失/矛盾 | 需求条目 + 规则库 → 缺陷清单（回映射到条目） | **Skill**（+ 可选 MCP） | LLM 可做基础版；如需严格约束求解，再挂形式化检查 MCP |
| 6 | 设计逻辑自洽性验证 | 查模块依赖循环、数据流断链、接口参数不匹配、状态机冲突 | 设计条目 → 缺陷清单（回映射到设计项） | **Skill**（+ 可选 MCP） | 同场景 5 |
| 7 | 需求/设计配图 | 由文本生成系统组成图/交联图/流程图/状态图 | 需求或设计文本 + 图表类型 → Mermaid/PlantUML + 渲染图 | **Skill** + 定制（渲染/预览） | skill 产出图脚本，渲染与导出复用 AgentEmployee 预览 / MCP 渲染服务 |
| 8 | 基于代码反推需求 | 解析代码库恢复软件需求规格 | 代码库路径 + 语言 → 需求条目（含依据文件、置信度） | **Skill** | 复用文件/grep/终端；如需符号索引再挂代码分析 MCP |
| 9 | 基于设计反推需求 / 基于代码反推设计 | 设计→需求、代码→设计的逆向推导 | 设计文档或代码库 → 反推需求/设计（标注来源） | **Skill** | 与场景 8 同一类逆推流程，模板不同；结果默认须用户确认 |
| 10 | 需求-设计双向追踪 | 建立需求↔设计追溯并算覆盖率 | 需求/设计条目 → 追踪矩阵 + 覆盖率 + 未覆盖告警 | **Skill**（建关系）+ **定制模块**（矩阵/覆盖率 UI） | 关系需要结构化存储与可视化页面，超出 skill 能力 |
| 11 | 智能润色 | 选中文本由模型润色并一键应用 | 文本片段 + 润色要求 → 1~3 个建议版本对比 | **Skill**（+ 复用编辑器动作） | 润色规则写进 skill；「选中并应用」复用现有编辑器/diff 交互 |
| 12 | 关联检出与联动修改 | 改一条后提示关联条目并建议同步修改 | 被改条目 ID → 关联条目列表 + 影响分析 | **Skill**（影响分析）+ **定制模块**（追溯图联动） | 依赖场景 10 的追踪图 |
| 13 | 执行中断与用户授权 | 关键节点自动暂停，人工确认后恢复 | 中断点 + 现场 → 授权界面 + 恢复执行 | **复用现有**（Permission / Plan 中断）+ **Skill** | AgentEmployee 天然支持权限/计划中断；skill 只需规定「哪些节点必须停下」 |
| 14 | 文档导入与解析 | 上传 docx/pdf/表格，抽取需求/设计要素 | 本地文档 → 结构化条目预览 | **Plugin**（文档解析 MCP） | 上传复用现有附件能力；解析需要外部解析引擎 |
| 15 | 文档导出与模板配置 | 按模板导出 Word/PDF，支持自定义模板 | 内容范围 + 模板 → 文档文件 | **定制模块**（转换服务 + 模板 UI） | 需要文档转换与模板管理页面 |
| 16 | 知识库检索 | 按上下文检索历史需求/知识增强生成 | 查询 + 参数 → 知识条目（含相似度、来源） | **Plugin**（向量库 MCP）+ **Skill** | 检索工具走 MCP；skill 规定如何引用与标注来源 |
| 17 | 知识库配置 | 配置向量库连接与权限 | 连接参数 → 连接测试 + 保存 | **定制模块**（配置页） | 属平台配置，非 agent 任务 |

## 三、平台侧能力（本轮不做，单列）

登录（本地/在线）、并发访问与空间隔离、备份与回退、日志管理、数据统计与上报、模型密钥加密存储与脱敏、"500 并发"等非功能指标 —— 这些与 agent 技能无关，需平台层单独实现。

## 四、落地优先级建议

1. **P0（纯 skill，最快见效）**：场景 1、2、3、4、8、9 —— 直接产出 `SKILL.md`，无需新代码。
2. **P1（skill + 现有工具）**：场景 5、6、7、11、13、16 —— 依赖附件/编辑器/预览等已有能力。
3. **P2（需 plugin / MCP）**：场景 14、16 —— 需要文档解析、向量检索工具。
4. **P3（需定制模块/页面）**：场景 10、12、15、17 —— 需要追溯矩阵、模板管理、配置页。
